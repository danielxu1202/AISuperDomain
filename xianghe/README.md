# 香乘新笺 · AI 合香师助手

React + Node.js + SQLite 的中式合香网页 MVP。AI 定位是**合香师助手**，不是替代老师傅，也不能在手机上生成气味。

合香讲究君臣佐使、香药同源、时令与体质，和西方香水调气味不是同一件事。本项目把《香乘》《陈氏香谱》常见香材与古方整理成可检索知识库，用规则 +（可选）大模型输出**可实操但仍须试香**的香方。

## 能做什么

1. **自然语言开方**：情绪 / 二十四节气 / 场景 / 「西湖落雪」「古寺庙的味道」等意象 → 君臣佐使克数、炮制、步骤、禁忌、香韵。
2. **民间方校验与优化**：拦截朱砂、雄黄、麝香、青木香等红线材料；把厚重古方改成更适合现代小户型的比例。
3. **手作助手**：打粉细度、粘粉比例、和泥湿度、阴干；按外观描述对照香材科普。
4. **数字香笺**：国风卡片，复制文本或截图分享。
5. **电熏演示**：低温电熏预设（办公醒神 / 睡前 / 梅雨）。明火线香不做自动控制。
6. **坊市与 VIP 演示**：免费每日 3 次；VIP 开关；原料包/工具带货货架（未接真实支付）。

## 安全红线（写进引擎，不是只写在文案里）

- 合香是嗅觉文化休闲，**不能替代治病**。
- 禁止：朱砂、雄黄、轻粉、铅丹、硫磺、青木香、细辛、苍耳子、麝香、阿魏等。
- 孕妇、哮喘、过敏在开方页可勾选，会改配方并提示。
- 密闭整夜卧室不建议燃香。
- 没有 API Key 时走本地知识库引擎，有 Key 时 RAG + 模型，输出仍做安全扫描。

## 技术

| 层 | 实现 |
| --- | --- |
| 前端 | React 18 + Vite + 国风 CSS，html2canvas 导出香笺 |
| 后端 | Express，端口 8787 |
| 数据 | SQLite（better-sqlite3）存香材、古方、开方记录、反馈、会员次数 |
| 检索 | 汉字二元语法 + TF-IDF，约束模型可用香材 |
| 模型 | 可选 OpenAI 兼容接口；未配置则纯本地开方 |

香材约 160 种，含木香、树脂、草木、花果、粘粉，以及明确标注的禁止项（用于拦截，不用于推荐）。

## 本地运行

```bash
cd xianghe
npm install
npm run install:all
npm test
npm run dev
```

- 网页：http://localhost:5173
- API：http://127.0.0.1:8787/api/health

可选：复制 `.env.example` 为 `server/.env`，填写 `OPENAI_API_KEY`（也可用国内兼容 `OPENAI_BASE_URL`）。

## 产品分层（本仓库先做第一层）

1. **纯软件（已做）**：Web 开方 / 校验 / 香笺 / 知识库。
2. **软硬结合（演示页）**：电熏炉料盒与温控预设；闭环是「香方 → 原料包」，不是电子鼻。
3. **商业**：会员、带货、B 端节气/文旅定制接口——页面有入口，支付未接。
