# 楚河汉界 · 人机中国象棋

浏览器里即可对弈的中国象棋，机器水平从入门到大师可调。

## 本地打开

在仓库根目录执行：

```bash
python3 -m http.server 8765
```

浏览器访问 [http://127.0.0.1:8765/xiangqi/](http://127.0.0.1:8765/xiangqi/)。

也可以直接打开 `xiangqi/index.html`。若浏览器拦截 Worker，大师级会退回主线程搜索，界面可能短暂卡顿。

## 难度

| 级别 | 说明 |
| --- | --- |
| 入门 | 只看一步，常出昏着 |
| 初级 | 浅层搜索，适合学走子 |
| 中级 | 开始用开局库，有基本攻防 |
| 高级 | 中等深度，能抢先手 |
| 专家 | 较深搜索，适合熟练棋手 |
| 大师 | 开局库 + 迭代加深 + 置换表 + 静态搜索，思考时间最长 |

大师级是本地 JavaScript 引擎的最强档，不是联网职业引擎；残局算杀和中局争夺会明显强于前几档。

## 规则

- 将帅不能照面
- 马蹩腿、象塞眼、相不过河、士帅不出九宫
- 炮需隔一子才能吃
- 将死、困毙都算负
- 同一局面出现三次，或 120 步无吃子、无进兵，作和
